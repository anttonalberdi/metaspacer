# Repository agent instructions

- Follow the milestones and review gates in `PROJECT_BRIEF.md`; do not cross a
  gate without the user's approval.
- Keep changes incremental, reviewable, and verified in proportion to their
  risk.
- At the end of every completed round of changes, explicitly ask the user
  whether they want that round committed.
- Do not create a commit without the user's confirmation, unless the user has
  already requested a commit for that round.
- When committing, include only the intended round of work and report the commit
  hash and verification performed.
